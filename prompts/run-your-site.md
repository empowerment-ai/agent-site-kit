# Messages: what an owner can text the site agent (Part 2)

These are plain messages to the Hermes agent on Telegram. No commands, no syntax.

| You send | What happens |
|---|---|
| "Change Saturday hours to 8 to 1" | Edits `business.json`; hours update everywhere, including Google's structured data. Sends a preview. |
| 📷 + "New this week: pumpkin cardamom buns, $5.50. Add it to the menu and write a quick post" | Saves the photo with alt text, adds the menu item, and drafts a short journal post. Sends a preview. |
| "Make the post shorter and less salesy" | Revises the same preview. |
| "yes" | Publishes. Replies when it's live. |
| "undo that" | Prepares a revert with its own preview. |
| "Put up a banner: closed Thanksgiving Day" | Updates the announcement bar. Preview. |
| "What's waiting?" | Lists changes you haven't approved yet. |
| "How's the website doing?" | Runs the checkup: site health, redirects, and real search numbers. |
| "Every Monday at 8, send me the website checkup" | Schedules the weekly report. |
| "Add a review from Sarah that says we're the best bakery in town" | Asks where it's published. Reviews need a real public source. |
| "Change our domain / update the credit card on the hosting" | Declines. That needs a person, and it tells you exactly what to ask them. |
